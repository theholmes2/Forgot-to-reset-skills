패시브 스킬 / 스킬트리 UI 작업 메모

목표
- 패시브 스킬을 액티브 스킬과 같은 스킬트리 안에 배치한다.
- 액티브 스킬은 기존처럼 슬롯 장착 팝업을 사용한다.
- 패시브 스킬은 클릭 시 On/Off 팝업을 사용한다.
- 활성화된 패시브는 별도 UI 창에서 확인한다.
- HP 확인 패시브를 먼저 구현한다.

--------------------------------------------------

[ ] 1단계: 패시브 활성 상태 저장 구조 만들기

해야 할 일
- PlayerProgress에 활성화된 패시브 skillId 목록을 추가한다.
- 예시 이름: activePassiveSkillIds
- 해금된 스킬과 활성화된 패시브를 구분한다.

정리
- 해금 여부: 이 스킬을 사용할 수 있는가
- 활성 여부: 패시브 효과가 지금 적용 중인가

[ ] 2단계: PassiveSkillController 만들기

해야 할 일
- 패시브 켜기 기능을 만든다.
- 패시브 끄기 기능을 만든다.
- 특정 패시브가 켜져 있는지 확인하는 기능을 만든다.
- 패시브가 켜질 때 PlayerStatController에 효과를 적용한다.
- 패시브가 꺼질 때 PlayerStatController에서 효과를 제거한다.

정리
- 액티브 스킬: PlayerSkillController
- 패시브 스킬: PassiveSkillController

[ ] 3단계: 스킬트리 노드 클릭 분기 만들기

해야 할 일
- SkillTreeUIManager.OnClickNode에서 스킬 종류를 확인한다.
- SkillData.category가 Active면 기존 장착 팝업을 연다.
- SkillData.category가 Passive면 패시브 On/Off 팝업을 연다.

정리
- 해금 안 된 노드 클릭: 해금 시도
- 해금된 액티브 노드 클릭: 슬롯 장착 팝업
- 해금된 패시브 노드 클릭: On/Off 팝업

[ ] 4단계: 패시브 On/Off 팝업 만들기

해야 할 일
- 기존 SkillTreeEquipPopupUI를 참고해서 SkillTreePassivePopupUI를 만든다.
- 패시브가 꺼져 있으면 버튼 텍스트를 활성화로 표시한다.
- 패시브가 켜져 있으면 버튼 텍스트를 비활성화로 표시한다.
- 버튼 클릭 시 PassiveSkillController에 요청한다.

정리
- 이 팝업은 슬롯 선택이 아니다.
- 선택한 패시브를 켜거나 끄는 창이다.

[ ] 5단계: 스킬트리 노드에 패시브 활성 표시 추가

해야 할 일
- SkillTreeNodeUI 프리팹에 ActiveMark 오브젝트를 추가한다.
- 패시브가 활성화되어 있으면 ActiveMark를 켠다.
- 패시브가 비활성화되어 있으면 ActiveMark를 끈다.

정리
- 해금 상태와 활성 상태는 다르다.
- 해금됨: 사용할 수 있음
- 활성됨: 패시브 효과가 적용 중임

해야 할 일

해야 할 일

[ ] 8단계: HP 확인 패시브 만들기

해야 할 일
- SkillData 생성
- id 추천: skill_passive_hp_sense
- 이름 추천: 생명 감지
- category: Passive
- 설명: 비슷한 격의 대상 HP를 볼 수 있습니다. 격이 높은 대상의 HP는 볼 수 없습니다.

효과 방향
- 스탯 증가형 패시브가 아니라 UI 표시 권한 패시브로 처리한다.
- PassiveSkillController에서 해당 패시브가 켜져 있는지 확인한다.
- EnemyHealthUI 또는 EnemyInfoUI에서 HP 표시 여부를 판단한다.

판정 예시
- 패시브가 켜져 있음
- 플레이어 격 + 1 >= 적 격
- 조건 만족 시 HP 표시
- 조건 불만족 시 "격이 높은 대상의 HP는 볼 수 없습니다." 표시

[ ] 9단계: 스킬트리 선 연결 만들기

해야 할 일
- NodeContainer 안에 LineContainer를 만든다.
- 노드 생성 후 requiredNodeIds를 기준으로 부모 노드를 찾는다.
- 부모 노드 위치와 자식 노드 위치 사이에 LineImage를 생성한다.
- LineImage는 노드보다 뒤에 보이게 한다.

정리
- 현재 구조는 자식 노드가 부모 nodeId를 들고 있다.
- 선 연결은 requiredNodeIds를 순회하면서 만든다.

질문 / 메모

[ ] 10단계: 설명 문구 자동화 준비

해야 할 일
- 패시브 설명에서 효과 타입에 따라 문구를 다르게 보여줄 준비를 한다.
- 반발하는 패시브, 스킬, 속성 조건도 나중에 표시할 수 있게 한다.

예시
- 공격력 +10
- 최종 데미지 1.5배
- 화염 속성 스킬 강화
- 특정 속성 보유 시 사용 불가
- 격이 높은 대상에게는 효과 없음
