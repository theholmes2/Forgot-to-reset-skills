# 공굴리기 게임
유니티 엔진의 기초와 C# 스크립팅을 학습하면서 완성한 기초 3D 플레이어 볼 굴리기 게임입니다.  

## 프로젝트 개요
- **설명** : 플레이어가 조작하는 공을 굴려 맵 내에 배치된 모든 아이템을 수집하는 직관적인 3D 캐주얼 게임입니다.
- **목적** : 유니티 에디터 인터페이스 익히기, 컴포넌트 구조 이해, C# 스크립트를 통한 물리 제어 및 UI 연동 기초 다지기.

## 주요 기능
- 물리 기반 플레이어 조작: 키보드 입력(WASD/방향키)을 받아 Rigidbody 컴포넌트에 힘(AddForce)을 가해 공을 이동시킵니다.
- 아이템 수집 시스템: OnTriggerEnter를 활용해 플레이어와 아이템의 충돌을 감지하고, 수집된 아이템은 화면에서 사라지며 점수가 올라갑니다.
- 오브젝트 회전 애니메이션: 아이템 큐브가 매 프레임마다 스스로 회전하여 시각적인 주목도를 높입니다.
- 카메라 추적 (Third-Person): 플레이어와 카메라 사이의 초기 거리값(Offset)을 유지하여 플레이어의 움직임을 부드럽게 추적합니다.
- UI 및 게임 루프: 실시간 획득 점수를 화면에 표시하며, 모든 아이템을 수집하면 "You Win!" 메시지를 출력합니다.

## 기술 스택 (Tech Stack)
- Engine: Unity 6
- Language: C#
- Platform: PC

## 어려웠던 점 & 해결 과정

1. 물리 기반 이동 시 관성 제어 문제
- 문제점: 공이 물리 법칙(Rigidbody.AddForce)으로 움직이다 보니, 키보드에서 손을 떼어도 관성 때문에 공이 너무 멀리 미끄러지거나 낙하하는 문제가 있었습니다.
- 해결과정: 플레이어 오브젝트의 Rigidbody 컴포넌트 내 Drag(마찰력) 속성 값을 조절하여 미끄러지는 범위를 제한했고, 상황에 따라 역방향 힘을 주거나 속도를 제한하는 방식으로 조작감을 개선했습니다.

2. 트리거 충돌 시 원치 않는 물리 반응
- 문제점: 아이템을 먹었을 때 자연스럽게 사라져야 하는데, 처음에는 공이 아이템과 부딪혀 튕겨 나가거나 멈추는 현상이 발생했습니다.
- 해결과정: 아이템 오브젝트 Collider 컴포넌트의 Is Trigger 옵션을 활성화하여 물리적 충돌(물리 벽)을 물리적 통과(이벤트 감지) 상태로 변경했습니다. 이후 OnTriggerEnter 함수를 사용해 충돌 감지와 스코어 처리를 구현했습니다.


## 알게 된 점 & 배운 점 (Retrospective)
- 컴포넌트 중심 아키텍처 이해: 유니티의 오브젝트들이 Transform, Rigidbody, Collider 등 독립적인 컴포넌트의 결합으로 작동하는 구조를 깊이 이해하게 되었습니다.
- Update와 FixedUpdate의 차이: 카메라 추적이나 연산은 Update/LateUpdate에서 처리하고, 물리적인 힘을 가하는 이동 로직은 프레임 레이트 독립성을 위해 FixedUpdate에서 처리해야 한다는 점을 배웠습니다.
- UI와 데이터 스크립팅 연동: 스크립트 내 변수 데이터(점수)가 변경될 때 UI Text 컴포넌트를 실시간으로 갱신하는 기본적인 UI 매니지먼트 흐름을 익혔습니다.
